# Volley Läufer

Unsere Läufer 1–6 in 3D: Annahme und Aufschlag als Animation, mit Libero und Durchlauf.

## Starten

```
npm install
npm run dev
```

## Anpassen

1. 5× Leertaste drücken (Handy: 5× auf die Überschrift tippen) → „✎ Bearbeiten“ erscheint
2. Spieler oder Ball ziehen
3. „JSON herunterladen“ und die Datei als `public/laeufer.json` ersetzen
